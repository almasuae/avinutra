# Image credits

Every photo used on the site is listed here with its source URL, author and licence
(Design Brief §4). Only the owner's own photos, or free-licence photos whose licence
allows commercial use without attribution, may be used. No images from other
companies' websites, and no AI images of real brands, bags or logos.

No photos are used yet. Until the owner approves images, the site uses brand shapes
only (circles, leaves, gradient panels, an abstract globe), which are drawn in code
and need no credit. The missing images are listed in `CONTENT-GAPS.md` (#13).

The logo files in `public/brand/` are generated from the owner's own artwork
(`docs/design/logo-source.png`) by `npm run brand:build`.
